## Seer: on-chain prediction markets (open source)

Front-end and smart-contract development · Oct 2024 – Jul 2025 · **42 merged pull requests** across the [Seer](https://github.com/seer-pm) app, airdrop contracts and landing page.
[See all merged pull requests →](https://github.com/seer-pm/demo/pulls?q=is%3Apr+is%3Amerged+author%3Ashan-pt)

- **Wallet connection:** correct account state after MetaMask auto-locks, keeping the displayed address and network switching reliable across browser restarts. ([#157](https://github.com/seer-pm/demo/pull/157), closes [#120](https://github.com/seer-pm/demo/issues/120))
- **Market price charts:** accurate tooltips for every scalar range, including narrow ones like 0–4 ([#285](https://github.com/seer-pm/demo/pull/285)); outlier filtering at the start of the graph ([#264](https://github.com/seer-pm/demo/pull/264)); graphs that stop once results are known ([#270](https://github.com/seer-pm/demo/pull/270)); a chart for every market, even before the first price data ([#224](https://github.com/seer-pm/demo/pull/224)).
- **Portfolio:** redeemable positions sorted first. ([#301](https://github.com/seer-pm/demo/pull/301), closes [#295](https://github.com/seer-pm/demo/issues/295))
- **Closed markets:** winning outcomes listed first, with check-mark icons for categorical and multi-categorical markets. ([#174](https://github.com/seer-pm/demo/pull/174), closes [#161](https://github.com/seer-pm/demo/issues/161))
- **Architecture:** shared logic extracted into reusable React hooks across 5 files. ([#188](https://github.com/seer-pm/demo/pull/188))
- **Smart contracts (Solidity):** airdrop contracts with a multi-token claim, an eligibility registry and an LP-point ERC-20 token ([#1](https://github.com/seer-pm/airdrop/pull/1)), plus governor token-withdraw functions ([#4](https://github.com/seer-pm/airdrop/pull/4)).
- **Responsive UI:** mobile and small-screen layouts across menus, modals, tables, forms and charts.
